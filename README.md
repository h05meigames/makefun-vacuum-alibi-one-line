## The line

> I did not miss that spot. My lidar classified it as a “decorative dust installation” and, per protocol, I left the art alone.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, UTF-8, no trailing newline, well within the
200-character limit.

## Run it

```sh
node main.ts
```
